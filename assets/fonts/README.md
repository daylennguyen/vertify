# Bundled fonts

These typefaces ship with the Flip Stage GUI (`vertify-gui`). Both are licensed under the SIL Open Font License 1.1.

| Family | Files used | Source |
|--------|------------|--------|
| **Syne** | `Syne-Regular.ttf`, `Syne-Bold.ttf` | [Bonjour Monde / Syne](https://gitlab.com/bonjour-monde/fonts/syne) |
| **Source Sans 3** | `SourceSans3-Regular.ttf`, `SourceSans3-SemiBold.ttf` | [Adobe Fonts / source-sans](https://github.com/adobe-fonts/source-sans) |

Variable fonts are included for completeness; the GUI currently embeds the static files listed above.

See `OFL.txt` in this directory for the license text.
